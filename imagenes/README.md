# Imágenes de Marbella Diversa

Carpeta para guardar las imágenes del proyecto: mapa de portada, sellos ilustrados del pasaporte virtual y fotografías de las paradas.

Convención sugerida: `mapa-portada.png`, `sello-04-plaza-naranjos.png`, etc.

Antes de publicar imágenes de terceros, comprobar los derechos y créditos correspondientes.
