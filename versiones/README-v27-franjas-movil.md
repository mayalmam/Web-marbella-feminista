# V27 · Unión de franjas y portada móvil

19 de octubre de 2026. Ajuste visual abierto a revisión.

- El dibujo mantiene su relación de aspecto real, también en móvil. Se elimina el estiramiento para llenar la altura del texto.
- Las franjas superiores usan la misma escala horizontal del dibujo; se elimina la línea de cabecera que atravesaba la unión y se solapan ocho píxeles para cubrir el borde transparente de la imagen.
- En móvil el texto y la ilustración ocupan la primera fila de composición; los accesos a rutas y pasaporte se sitúan debajo, antes del mapa completo.
- El mapa, el pasaporte, las trece fichas y el JavaScript no se modifican.
- Se incorpora una página auxiliar de revisión a 390 px en `revision-movil-v27.html`, fuera de la navegación principal.

Versiones anteriores conservadas. Estilos adicionales: `assets/futuro-memoria-v27.css`.
